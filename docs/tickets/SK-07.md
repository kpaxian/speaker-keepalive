## Session handoff — 2026-10-04

### Implemented

Added [systemd/speaker-keepalive.service](../../systemd/speaker-keepalive.service):

```ini
[Unit]
Description=Speaker keepalive pulses on the default audio output

[Service]
Type=simple
ExecStart="%h/.local/bin/speaker-keepalive" run
Restart=on-failure
RestartSec=10s
KillSignal=SIGINT
KillMode=mixed
TimeoutStopSec=5s

[Install]
WantedBy=default.target
```

The quoted `%h` path expands to the user's home directory. The service invokes
foreground `run`, retaining 30 s / 300 ms / 100 Hz / 0.0005 defaults. SIGINT uses
the application's existing cleanup handler; mixed kill mode initially signals
the parent and lets systemd kill remaining service processes if needed. No
PipeWire startup-order dependency is assumed. Application-level transient
failures retain their existing retry policy; process failures restart after 10 s.

The [README setup section](../../README.md#start-automatically-at-login) contains
copy/build, verify/reload, enable/start, status/journal, stop/disable, upgrade and
removal instructions. Installation uses the user's configuration directory and
keeps overwritten-file backups; activation remains a separate explicit command.
No files were installed outside the repository and no service was enabled.
No lingering settings, audio settings, CLI code, or dependencies were changed.

Updated SK-06 and the worksheet with the user's reports: JBL on at 1650 s,
longer than its usual idle timeout by personal experience; no artifacts reported;
visually negligible resource use; parent stopped after Ctrl+C. No exact baseline,
CPU/RSS, route evidence, or child cleanup observation was invented. The index
records the explicit user-authorized change in ticket order.

4. In a controlled running-service session, record MainPID/NRestarts, simulate a
   main-process crash, then check again after at least ten seconds:

   ```bash
   systemctl --user show speaker-keepalive.service -p MainPID -p NRestarts
   systemctl --user kill --kill-whom=main --signal=SIGKILL speaker-keepalive.service
   ```

   Wait at least ten seconds, then:

   ```bash
   systemctl --user show speaker-keepalive.service -p MainPID -p NRestarts
   systemctl --user status speaker-keepalive.service
   ```

   Expect a new running PID, incremented restart count, and no previous child
   left behind. This deliberately restarts playback; do it only during the
   observed service test, not as part of ordinary installation.
5. With the service enabled, log out and back in at a convenient time and check
